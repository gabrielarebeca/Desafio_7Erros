# 🔍 Desafio 7 Erros

Este repositório contém a solução para o **desafio dos 7 erros**, um jogo interativo onde o usuário deve identificar as diferenças entre duas imagens aparentemente iguais.

## 📌 Sobre o Projeto

O projeto consiste em um **jogo de 7 erros** onde o jogador precisa encontrar as 7 diferenças entre duas imagens. O jogo fornece um feedback ao usuário após ele tentar identificar todas as diferenças, e a pontuação é calculada com base no desempenho.

## ⚙️ Funcionalidades

- 🖼️ Apresentação de **duas imagens** com 7 diferenças
- 🕹️ Identificação das **diferenças** entre as imagens
- 📊 Feedback sobre o número de acertos e erros
- 🎯 Pontuação baseada na quantidade de erros cometidos
- 📱 Layout responsivo para diferentes dispositivos

## 🛠 Tecnologias Utilizadas

- **HTML5**
- **CSS3** (para o design das páginas e imagens)
- **JavaScript** (para a lógica do jogo e interação)
