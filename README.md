# 🔍 Desafio 7 Erros

## 📌 Sobre o Projeto

Aplicação web simples desenvolvida com HTML e JavaScript que permite adicionar nomes de filmes a uma lista dinâmica.

O objetivo do projeto é praticar manipulação do DOM, interação com formulários e atualização dinâmica da interface no navegador.

🔗 Visualizar o projeto:
https://gabrielarebeca.github.io/Desafio_7Erros/

⚙️ Funcionalidades

- Adicionar filmes a uma lista
- Exibir os filmes adicionados na tela
- Interface simples e intuitiva
- Atualização dinâmica sem recarregar a página

🛠️ Tecnologias Utilizadas

- HTML5
- JavaScript
- GitHub Pages para deploy
